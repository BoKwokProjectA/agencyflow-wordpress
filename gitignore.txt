# =====================================================================
#  AgencyFlow .gitignore
#
#  This repository lives at the WordPress root, but it only tracks the
#  code that is actually mine: the custom theme, the custom plugin, the
#  tests, the CI workflow and the documentation.
#
#  Everything else is deliberately excluded, for three reasons:
#    1. WordPress core is third-party code, downloadable from
#       wordpress.org. Committing it bloats the repo and creates merge
#       conflicts on every WordPress update.
#    2. wp-config.php holds database credentials and the secret
#       authentication salts. Committing it is a real security incident.
#    3. Uploads are content, not code. They belong in a backup, not in
#       version control.
# =====================================================================
